# Hello JavaScript

A beginner JavaScript practice repository containing small experiments and first-step programming exercises.

## 🎯 Purpose

This repository represents the early stage of my JavaScript learning journey. It is used to practice syntax, variables, console output, simple scripts and basic browser-based JavaScript.

## 🧠 Learning Areas

- JavaScript syntax
- Console output
- Variables and data types
- Operators
- Functions
- Conditions
- Loops
- Basic browser interaction
- Connecting JavaScript with HTML

## 📁 Project Structure

```text
hello-js/
├── HTML/
│   └── index.html
├── index.js
├── intro.js
├── new.js
├── .hintrc
└── README.md
```

### File overview

- `index.js` — first "Hello, World!" JavaScript example
- `intro.js` — simple variables and console-output practice
- `new.js` — scratch/practice file for future JavaScript experiments
- `HTML/index.html` — basic browser page for connecting HTML and JavaScript
- `.hintrc` — web development hints configuration

## ▶️ Running the JavaScript

For the standalone JavaScript files, use a modern browser console or a JavaScript runtime such as Node.js:

```bash
node index.js
node intro.js
```
